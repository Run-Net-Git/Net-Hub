🌐 មេរៀនប្រព័ន្ធបណ្ដាញកុំព្យូទ័រ (Networking)

១. អ្វីទៅជា Network?
Network គឺជានិយមន័យនៃការតភ្ជាប់កុំព្យូទ័រ ឬឧបករណ៍អេឡិចត្រូនិកចាប់ពីពីរឡើងទៅ ដើម្បីចែករំលែកទិន្នន័យ ធនធាន និងសេវាកម្មផ្សេងៗ។
២. ប្រភេទ IP Address
IP Address មានពីរប្រភេទសំខាន់ៗគឺ៖
  • IPv4: ទម្រង់ 32-bit (ឧទាហរណ៍៖ 192.168.1.1)
  • IPv6: ទម្រង់ 128-bit ប្រើសម្រាប់ជំនួស IPv4 ដែលខ្វះខាត
៣. អ្វីទៅជា Subnetting?
Subnetting គឺជាការបែងចែកបណ្ដាញ Network ធំមួយ ឱ្យទៅជាបណ្ដាញតូចៗ (Subnets) ដើម្បីបង្កើនប្រសិទ្ធភាព និងសុវត្ថិភាពក្នុងការគ្រប់គ្រង។
៤. ស្គាល់ពី OSI Model ទាំង ៧ Layer
OSI Model គឺជាគំរូស្តង់ដារដែលពន្យល់ពីដំណើរការនៃការផ្ញើ និងទទួលទិន្នន័យ៖

Application ➔ Presentation ➔ Session ➔ Transport ➔ Network ➔ Data Link ➔ Physical Layer

៥. ឧបករណ៍បណ្ដាញទូទៅ (Network Devices)
Router ប្រើសម្រាប់តភ្ជាប់បណ្ដាញផ្សេងៗគ្នា និងចង្អុលផ្លូវទិន្នន័យ (Routing)។
Switch ប្រើសម្រាប់តភ្ជាប់ឧបករណ៍ជាច្រើនក្នុងបណ្ដាញតែមួយ (LAN)។
