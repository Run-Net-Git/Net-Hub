🌐 មេរៀនប្រព័ន្ធបណ្តាញកុំព្យូទ័រ (Networking)

១. អ្វីទៅជា Network?

Network គឺជាការតភ្ជាប់កុំព្យូទ័រ ឬឧបករណ៍អេឡិចត្រូនិចចាប់ពីពីរឡើងទៅ ដើម្បីចែករំលែកទិន្នន័យ និងធនធានផ្សេងៗ...

២. ប្រភេទ IP Address

IP Address មានពីរប្រភេទធំៗគឺ IPv4 (32-bit) និង IPv6 (128-bit)...

៣. អ្វីទៅជា Subnetting?

Subnetting គឺជាការបែងចែកបណ្ដាញ Network ធំមួយ ឱ្យទៅជាបណ្ដាញតូចៗ (Subnets) ដើម្បីបង្កើនប្រសិទ្ធភាព និងសុវត្ថិភាពក្នុងការគ្រប់គ្រង។

៤. ស្គាល់ពី OSI Model ទាំង ៧ Layer

OSI Model គឺជាគំរូស្តង់ដារដែលពន្យល់ពីដំណើរការនៃការផ្ញើ និងទទួលទិន្នន័យ៖ Application, Presentation, Session, Transport, Network, Data Link, និង Physical Layer។

៥. ឧបករណ៍បណ្ដាញទូទៅ (Network Devices)

Router: ប្រើសម្រាប់តភ្ជាប់បណ្ដាញផ្សេងៗគ្នា និងចង្អុលផ្លូវទិន្នន័យ (Routing)។
Switch: ប្រើសម្រាប់តភ្ជាប់ឧបករណ៍ជាច្រើនក្នុងបណ្ដាញតែមួយ (LAN)។
