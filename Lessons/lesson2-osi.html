⬅️ ត្រឡប់ទៅបណ្ដុំមេរៀន

មេរៀនទី ២: OSI Model ទាំង ៧ Layer

១. អ្វីទៅជា OSI Model?

OSI (Open Systems Interconnection) Model គឺជាគំរូស្តង់ដារមួយដែលត្រូវបានបង្កើតឡើងដើម្បីពន្យល់ពីរបៀបដែលទិន្នន័យត្រូវបានបញ្ជូនពីឧបករណ៍មួយទៅឧបករណ៍មួយទៀតតាមរយៈប្រព័ន្ធបណ្ដាញ (Network) ដោយបែងចែកវាជា ស្រទាប់ (Layers) ចំនួន ៧។

២. ស្រទាប់ទាំង ៧ របស់ OSI Model

  • Layer 7 - Application Layer: ជាស្រទាប់ជាប់ទាក់ទងនឹងអ្នកប្រើប្រាស់ផ្ទាល់ ឧទាហរណ៍៖ HTTP, FTP, DNS។
  • Layer 6 - Presentation Layer: ធ្វើការបកប្រែទ្រង់ទ្រាយទិន្នន័យ ការអ៊ិនគ្រីប (Encryption) និងការបង្ហាប់ទិន្នន័យ (Compression)។
  • Layer 5 - Session Layer: គ្រប់គ្រងការបង្កើត រក្សា និងបិទទំនាក់ទំនង (Sessions) រវាងកម្មវិធីទាំងពីរ។
  • Layer 4 - Transport Layer: ធានាការបញ្ជូនទិន្នន័យដោយសុវត្ថិភាព តាមរយៈ TCP ឬ UDP។
  • Layer 3 - Network Layer: ធ្វើការជ្រើសរើសផ្លូវ (Routing) និងប្រើប្រាស់ IP Address ដើម្បីបញ្ជូនទិន្នន័យ[cite: 17]។
  • Layer 2 - Data Link Layer: គ្រប់គ្រងការផ្ទេរទិន្នន័យក្នុង Network តែមួយ ដោយប្រើប្រាស់ MAC Address[cite: 17]។
  • Layer 1 - Physical Layer: ជាស្រទាប់ භូតិសាស្ត្រ ដែលបម្លែងទិន្នន័យទៅជាសញ្ញាអគ្គិសនី ឬពន្លឺឆ្លងកាត់ខ្សែបណ្ដាញ (Cables)។

៣. សារៈសំខាន់នៃ OSI Model

វាជួយឱ្យអ្នកបច្ចេកទេសបណ្ដាញ (Network Engineers) ងាយស្រួលក្នុងការស្វែងរកកំហុសឆ្គង (Troubleshooting) និងធ្វើឱ្យផលិតផលពីក្រុមហ៊ុនផ្សេងគ្នាអាចប្រើប្រាស់ជាមួយគ្នាបាន។
