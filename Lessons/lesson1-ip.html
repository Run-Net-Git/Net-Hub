មេរៀនទី ១: IP Address & Subnetting

១. អ្វីទៅជា IP Address?

IP Address (Internet Protocol Address) គឺជាអាសយដ្ឋានសម្គាល់ឧបករណ៍នីមួយៗដែលភ្ជាប់នៅក្នុងប្រព័ន្ធ Network ដើម្បីឱ្យពួកវាអាចប្រាស្រ័យទាក់ទងគ្នាបាន។

២. ប្រភេទនៃ IP Address

  • IPv4: ជាទម្រង់ 32-bit ដែលមាន 4 octets ឧទាហរណ៍៖ 192.168.1.1
  • IPv6: ជាទម្រង់ 128-bit ដែលបង្កើតឡើងដើម្បីជំនួស IPv4 ឧទាហរណ៍៖ 2001:0db8:85a3::8a2e:0370:7334

៣. អ្វីទៅជា Subnetting?

Subnetting គឺជាដំណើរការនៃការបែងចែក Network ធំមួយ ឱ្យទៅជា Network តូចៗជាច្រើន ដើម្បីគ្រប់គ្រងទិន្នន័យបានល្អ និងបង្កើនសុវត្ថិភាព។

៤. អ្វីទៅជា Subnet Mask?

Subnet Mask គឺជាអាសយដ្ឋានសម្គាល់ដែលប្រើប្រាស់ដើម្បីគ្រប់គ្រងការចែក Network ជា Subnets។

៥. តើ IPv4 មានទម្រង់ដូចម្តេច?

IPv4 មានទំហំ 32-bit ហើយចែកជា 4 octets។ Octet នីមួយៗមានតម្លៃពី 0 ដល់ 255។

៦. តើ IPv6 មានទម្រង់ដូចម្តេច?

IPv6 គឺជាជំនាន់ថ្មីរបស់ Internet Protocol ដែលមានទំហំ 128-bit ហើយត្រូវបានបង្កើតឡើងដើម្បីផ្គត់ផ្គង់ IP Address ច្រើនជាង IPv4។

៧. អ្វីទៅជា Public និង Private IP Address?

Public IP Address គឺជាអាសយដ្ឋានដែលមានសេរិយភាពនៅលើ Internet ហើយអាចចូលដំណើរការបានពីក្នុងនិងខាងក្រៅ Network។ Private IP Address គឺជាអាសយដ្ឋានដែលប្រើប្រាស់នៅក្នុង LAN ហើយមិនអាចចូលដំណើរការបានពីក្នុងនិងខាងក្រៅ Network។

៨. តើ Subnetting មានអត្ថប្រយោជន៍អ្វីខ្លះ?

  • បង្កើនសុវត្ថិភាពក្នុង Network
  • គ្រប់គ្រងទិន្នន័យបានល្អ
  • បង្កើនប្រសិទ្ធភាពក្នុងការប្រើប្រាស់ IP Address

៩. តើ Public IP Address ជាអ្វី?

Public IP Address គឺជា IP Address ដែលអាចប្រើសម្រាប់ទំនាក់ទំនងជាមួយ Network ឬ Internet ខាងក្រៅ។ ជាទូទៅវាត្រូវបានផ្តល់ដោយ ISP។

១០. តើ Private IP Address ជាអ្វី?

Private IP Address គឺជា IP Address ដែលប្រើសម្រាប់ Network ខាងក្នុង (LAN) ហើយមិនអាចប្រើសម្រាប់ទំនាក់ទំនងជាមួយ Network ឬ Internet ខាងក្រៅ។

១១. តើ Loopback IP Address ជាអ្វី?

Loopback IP Address គឺជា IP Address ដែលប្រើសម្រាប់ការធ្វើតេស្តការទំនាក់ទំនងនៅក្នុងឧបករណ៍តែមួយ។ ជាទូទៅវាជា 127.0.0.1។

១២. តើ Subnet Mask ជាអ្វី?

Subnet Mask គឺជាតម្លៃដែលប្រើដើម្បីបែងចែក Network Portion និង Host Portion របស់ IP Address។ ឧទាហរណ៍៖ 255.255.255.0 ឬ /24.

១៣. តើ Default Gateway ជាអ្វី?

Default Gateway គឺជាឧបករណ៍ (ជាទូទៅជា Router) ដែលភ្ជាប់ Network ខាងក្នុងទៅ Network ខាងក្រៅ ឬ Internet។

១៤. តើ DNS (Domain Name System) ជាអ្វី?

DNS គឺជាប្រព័ន្ធដែលបម្លែងឈ្មោះដែន (Domain Names) ទៅជា IP Address ដើម្បីឱ្យឧបករណ៍អាចស្វែងរកគ្នាបានលើ Internet។

១៥. តើ DHCP (Dynamic Host Configuration Protocol) ជាអ្វី?

DHCP គឺជាប្រព័ន្ធដែលផ្តល់ IP Address និង Subnet Mask ដោយស្វ័យប្រវត្តិទៅឧបករណ៍នៅក្នុង Network ដើម្បីងាយស្រួលក្នុងការកំណត់ Network Settings។

១៦. តើ Network Protocols ជាអ្វី?

Network Protocols គឺជាការកំណត់ច្បាប់ និងវិធីសាស្រ្តដែលឧបករណ៍ ប្រើប្រាស់ដើម្បីទំនាក់ទំនងគ្នានៅក្នុង Network។ ឧទាហរណ៍៖ TCP/IP, HTTP, FTP, SMTP។

១៧. តើ Network Address ជាអ្វី?

Network Address គឺជា IP Address ដែលតំណាងឱ្យ Network ទាំងមូល ហើយមិនអាចកំណត់ឱ្យ Device មួយជាក់លាក់បានទេ។ ឧទាហរណ៍៖ 192.168.1.0/24

  • ឧទាហរណ៍៖ 192.168.1.0/24

    • ១៨. តើ Broadcast Address ជាអ្វី?

    Broadcast Address គឺជា IP Address ដែលប្រើសម្រាប់ផ្ញើ Data ទៅកាន់ Device ទាំងអស់នៅក្នុង Network ដូចគ្នា។

  • ឧទាហរណ៍៖ សម្រាប់ 192.168.1.0/24 Broadcast Address គឺ 192.168.1.255

    • ១៩. តើ Host Address ជាអ្វី?

    Host Address គឺជា IP Address ដែលអាចកំណត់ឱ្យ Computer, Phone, Printer, Server ឬឧបករណ៍ផ្សេងៗនៅក្នុង Network។

  • ឧទាហរណ៍៖ 192.168.1.10

    • ២០. តើ APIPA ជាអ្វី?

    APIPA (Automatic Private IP Addressing) គឺជា Feature ដែលអាចប្រើដើម្បីផ្តល់ IP Address ដោយស្វ័យប្រវត្តិទៅឧបករណ៍នៅក្នុង Network ដែលមិនមាន DHCP Server ទាក់ទាញ។
