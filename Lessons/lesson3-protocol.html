⬅️ ត្រឡប់ទៅបណ្ដុំមេរៀន

មេរៀនទី ៣: Network Protocols (DHCP & DNS)

១. អ្វីទៅជា Network Protocol?

Network Protocol គឺជាសំណុំនៃច្បាប់ ឬបទដ្ឋានដែលកំណត់ពីរបៀបដែលទិន្នន័យត្រូវទ្រង់ទ្រាយ បញ្ជូន និងទទួលបានរវាងឧបករណ៍ផ្សេងៗគ្នានៅក្នុងប្រព័ន្ធបណ្ដាញ (Network)។

២. សេវាកម្ម DHCP (Dynamic Host Configuration Protocol)

DHCP គឺជាប្រព័ន្ធស្វ័យប្រវត្តិដែលមាននាទីក្នុងការផ្តល់ IP Address, Subnet Mask, Gateway និង DNS ទៅឱ្យឧបករណ៍នីមួយៗដែលភ្ជាប់ចូលមកក្នុង Network ដោយមិនបាច់កំណត់ដោយដៃ (Manual) នោះឡើយ។

  • អត្ថប្រយោជន៍៖ ជួយកាត់បន្ថយកំហុសឆ្គងក្នុងការកំណត់ IP និងងាយស្រួលគ្រប់គ្រងឧបករណ៍ច្រើន។

៣. សេវាកម្ម DNS (Domain Name System)

DNS ทำหน้าที่ប្រៀបដូចជា "កាតព៌ត័មាន (Phonebook)" របស់អ៊ីនធឺណិត ដែលធ្វើការបកប្រែឈ្មោះគេហទំព័រដែលមនុស្សងាយចាំ (ឧទាហរណ៍៖ google.com) ទៅជាលេខ IP Address (ឧទាហរណ៍៖ 142.250.190.46) ដើម្បីឱ្យកុំព្យូទ័រអាចស្គាល់គ្នាបាន។

៤. សារៈសំខាន់របស់ DHCP និង DNS

បើសគ្មាន DHCP យើងត្រូវកំណត់ IP ឱ្យកុំព្យូទ័រនីមួយៗដោយដៃផ្ទាល់ ហើយបើសគ្មាន DNS យើងត្រូវចាំលេខ IP វែងៗដើម្បីចូលមើលវេបសាយ ដែលវាពិបាកខ្លាំងណាស់សម្រាប់អ្នកប្រើប្រាស់។
