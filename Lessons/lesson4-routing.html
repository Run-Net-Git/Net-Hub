មេរៀនទី ៤: Routing & Switching

១. អ្វីទៅជា Router?

Router គឺជាឧបករណ៍ Network ដែលមានតួនាទីក្នុងការភ្ជាប់ Network ខុសៗគ្នា (ឧទាហរណ៍៖ LAN និង WAN) និងស្វែងរកផ្លូវល្អបំផុតក្នុងការបញ្ជូនទិន្នន័យ (Packets)។

២. អ្វីទៅជា Switch?

Switch គឺជាឧបករណ៍ប្រើសម្រាប់ភ្ជាប់ឧបករណ៍កុំព្យូទ័រជាច្រើនចូលគ្នានៅក្នុង Network តែមួយ (Local Area Network - LAN) ដោយប្រើប្រាស់ MAC Address ដើម្បីបញ្ជូនទិន្នន័យ។

៣. ភាពខុសគ្នារវាង Router និង Switch

  • Router: ធ្វើការនៅ Layer 3 (Network Layer) និងប្រើ IP Address[cite: 17]។
  • Switch: ធ្វើការនៅ Layer 2 (Data Link Layer) និងប្រើ MAC Address[cite: 17]។
